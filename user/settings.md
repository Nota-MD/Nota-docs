# 设置与外观

使用 `Ctrl+,` 打开偏好设置。改动即时生效，右上角关闭按钮或 `Esc` 可退出。

## 界面风格与文档主题

Nota 有两条独立的外观轴：

- **界面风格**：菜单、侧栏、按钮、间距、图标与界面字体
- **文档主题**：正文页面、标题、代码块与正文排版

切换界面风格不会自动改变文档主题。

## 浅色与深色

明暗模式可以：

- 跟随系统
- 固定浅色
- 固定深色

文档主题也可单独指定深色模式下使用的另一套主题。

## 字体大小与缩放

- **字体大小**只改变界面文字大小
- **界面缩放**同时改变文字、图标和间距

## 拼写检查

Nota 不随应用分发 Hunspell 词典。可在 **设置 → 编辑器 → 拼写检查** 中：

- 使用系统已安装词典
- 导入包含 `.aff` 与 `.dic` 的 ZIP 包
- 打开词典目录，手动放入两个词典文件

可同时选择多种语言，并维护自己的用户词典。

## 恢复默认

“通用”页提供恢复出厂设置。执行前请阅读页面上的范围说明；插件设置文件和上传密钥不会
被一并清除。
