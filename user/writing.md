# 第一次写作

## 新建文档

从 **文件 → 新建** 创建文档，输入内容后使用 `Ctrl+S` 保存。

Nota 在输入 Markdown 标记时直接显示排版结果。例如输入 `# 标题`，该行会立即成为标题；
保存到磁盘的内容仍然是 `# 标题`。

## 常用标记

```markdown
# 一级标题
## 二级标题

**粗体**
*斜体*
`行内代码`

- 项目
- 项目

> 引用
```

## 源码模式

使用 `Alt+1`、`Alt+2` 或 `Ctrl+/` 切换所见即所得、源码和分屏模式。

源码模式适合检查原始 Markdown、处理表格空格或排查扩展语法。

## 查找与替换

- `Ctrl+F`：查找
- `Ctrl+H`：查找并替换

查找高亮不会写入文档，也不会进入撤销记录。

## 自动保存

自动保存默认关闭。可以在 **设置 → 文件** 中：

- 开启切换文件时自动保存
- 设置定时自动保存间隔
- 恢复未保存草稿

无论是否开启自动保存，关闭含未保存改动的窗口时仍会先询问。
