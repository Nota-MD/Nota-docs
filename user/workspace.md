# 工作区、标签页与大纲

## 打开工作区

从 **文件 → 打开文件夹** 选择一个目录。左侧“文件”页会显示支持的 Markdown 和文本文件。

Nota 只读取你明确打开的工作区，不会扫描整个主目录。

## 标签页

打开多个文件会形成标签页。标签上的圆点表示尚未保存。

常用操作：

- `Ctrl+S`：保存当前文档
- `Ctrl+Shift+S`：另存为
- `Ctrl+W`：关闭当前标签页
- 标签页右键：在新窗口中打开、重命名、移动或关闭

## 大纲

左侧“大纲”页从当前文档的标题生成目录。点击条目可跳到对应标题。

严格模式开启时，`#标题` 不算标题，必须写成 `# 标题`。

## 外部修改

工作区中的文件被其他程序修改后，Nota 会显示提示，并允许：

- 查看磁盘版本与编辑器版本的差异
- 使用磁盘版本替换编辑器内容
- 保留编辑器内容

替换前会先询问，未保存内容不会静默丢失。
