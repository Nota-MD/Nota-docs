# 安装主题

官方主题维护在 [Nota-themes](https://github.com/Nota-MD/Nota-themes)。

Nota 把界面主题和文档主题分开：

- **界面主题**改变应用外壳
- **文档主题**改变正文页面

## 界面主题

1. 打开 **设置 → 外观**
2. 选择 **风格文件夹…**
3. 将主题的 CSS 和它引用的资源放入该目录
4. 返回 Nota，在“界面风格”中选择主题

主题 CSS 可以引用相对路径中的图片、图标和字体。资源必须与 CSS 保持在允许目录内。

## 文档主题

1. 打开 **设置 → 文档主题**
2. 选择 **打开…**
3. 将 `.css` 文件放入主题目录
4. 从 **主题** 菜单选择

文档主题只影响编辑区，不会改变侧栏、菜单或按钮。

## 首选字体缺失

主题指定的首选字体不存在时，Nota 会提示。可以将字体安装到系统，或使用主题包随附的
字体；安装随附字体时请同时保留许可证文件。
