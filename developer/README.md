# 开发者文档

Nota 的三条开发路线彼此独立：

| 路线 | 适合 | 起点 |
|---|---|---|
| 主程序 | 修改编辑器、桌面集成、核心功能 | [贡献主程序](core/README.md) |
| 拓展 | 用 Lua 增加命令、面板和数据 | [编写拓展](extensions/README.md) |
| 主题 | 只通过 CSS 与资源改变外观 | [编写主题](themes/README.md) |

三条路线都要求提交者亲自完成测试。AI 可以参与代码、测试和文档，但不能代替提交者理解
改动、核对许可证或声明测试结果。

## 共同原则

1. 先读现有实现，再写第二个版本。
2. 一次只解决一件事。
3. 代码与文档同批完成。
4. 涉及界面的改动必须在真实窗口中操作。
5. 不复制来源或许可不清楚的代码、字体、图标和主题素材。
