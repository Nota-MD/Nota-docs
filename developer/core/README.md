# 贡献主程序

这条路线面向修改 Nota 核心的贡献者。Nota 由 Rust/Tauri 后端和 React/TypeScript 前端
组成，编辑器内核是 Milkdown/ProseMirror。

阅读顺序：

1. [准备开发环境](01-setup.md)
2. [认识代码结构](02-architecture.md)
3. [完成第一个改动](03-first-change.md)
4. [运行测试并同步文档](04-testing.md)
5. [提交 Pull Request](05-pull-request.md)

开始前必须阅读主仓库根目录的 [`AGENTS.md`](https://github.com/Nota-MD/Nota/blob/main/AGENTS.md)
和 [`CONTRIBUTING.md`](https://github.com/Nota-MD/Nota/blob/main/CONTRIBUTING.md)。
