# 提交 Pull Request

## 分支

从最新 `main` 创建聚焦分支：

```sh
git switch main
git pull
git switch -c fix/menu-focus
```

## 提交信息

提交信息应说明问题和结果，而不是只写“update”。

```text
修复侧栏关闭后焦点落回正文

关闭侧栏时把焦点交给当前编辑区，避免焦点留在已卸载的按钮上。
```

## PR 内容

使用主仓库 PR 模板，逐项填写：

- 改动目标
- AI 参与范围
- 测试环境
- 实际操作步骤
- 实际结果
- 未验证边界
- 截图、录屏或日志

## 合并前

- 所有自动检查通过
- 审查意见已处理
- 提交者亲自完成主路径和错误路径测试
- 代码、文档、第三方清单保持同步

不要强制推送已进入公共审查的分支。
