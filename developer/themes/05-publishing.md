# 测试与发布

## 1. 界面主题测试矩阵

至少检查：

- 浅色
- 深色
- 菜单打开与悬停
- 侧栏、标签栏、状态栏
- 设置对话框
- 输入框焦点
- 禁用按钮
- 长文件树与滚动条

## 2. 文档主题测试矩阵

至少检查：

- 标题六级
- 粗体、斜体、删除线
- 引用、列表、任务列表
- 表格
- 行内代码与代码块
- 公式
- 图表
- 图片与视频
- 打印和 HTML 导出

## 3. 字体检查

- 字体在原尺寸下清晰
- 中文和西文都能显示
- 粗体不是错误合成
- 缺失字体时有合理后备
- 字体许可证随主题分发

## 4. 发布结构

推荐一个主题包包含：

```text
theme-name/
├── theme.css
├── README.md
├── LICENSE
└── assets/
```

README 应说明：

- 对应 Nota 版本
- 安装到哪个目录
- CSS 最终文件名
- 字体和图标来源
- 已知限制

## 5. 官方主题

官方主题提交到 [Nota-themes](https://github.com/Nota-MD/Nota-themes)。

第三方主题可以独立发布，但不要要求主程序加入该主题的专用代码。

## 6. 发布前最后检查

- 资源相对路径完整
- 没有目录穿越
- 没有未授权素材
- 浅色和深色都能读
- 所有控件焦点可见
- 至少一套真实文档完成目检
- 安装与卸载步骤可复现
