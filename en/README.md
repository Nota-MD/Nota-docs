# Nota Documentation

Nota is a local-first WYSIWYG Markdown editor with a Lua extension system.

The complete tutorials are currently maintained in Simplified Chinese. The public
entry points are:

- [User guide](../user/README.md)
- [Contributing to Nota](../developer/core/README.md)
- [Writing an extension](../developer/extensions/README.md)
- [Writing a theme](../developer/themes/README.md)

Source code and reference documentation are available in the
[Nota repository](https://github.com/Nota-MD/Nota).
